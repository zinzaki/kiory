# Kiory v7 — Спецификация, поштучный аудит и список изменений

## 1. Итоги финальной ревизии и отбора (`Untitled.figcraft`)
- **Чистая архитектура из 352 иконок**: полностью удалены 32 чужеродные буквальные иконки из референсов (`tear-mark`, `lily`, `zen-circle`, `leaf`, `gem` и др.). Эстетика референсов (пластика слезинки под глазом персонажа Ivy Hart, каплевидные утолщения на концах разрывов, плотные пропорции Onyx) интегрирована в геометрию, изгибы и пропорции самих интерфейсных иконок.
- **Точное применение пользовательского отбора из `Untitled.figcraft`**:
  - `face-id` — зафиксирована единственная оставленная пользователем версия (`v3_contour_laser`: 4 скругленные угловые скобки сканера + контур головы + горизонтальный лазерный луч сканирования).
  - `search` — линза с плавным каплевидным утолщением у разрыва и отделенной рукояткой (по мотивам референса 3).
  - `circle` — разомкнутое кольцо с плавным каплевидным окончанием и сателлитной точкой.
  - `chevrons-left` / `chevrons-right` — двойные шевроны с фирменным разрывом и каплевидной точкой.
  - `truck` — чистый силуэт грузовика доставки с выверенными колесными арками.
  - `bell`, `bell-off`, `notification` — полностью унифицированы на базе единого корпуса `MASTER_BELL`.
  - `camera`, `camera-off` — полностью унифицированы на базе единого корпуса `MASTER_CAMERA`.
  - `fingerprint` — концентрические C1-гладкие дуги с фирменными разрывами и воздушными зазорами.
  - `plugin` — скругленный squircle-модуль расширения без острых углов.
  - `webhook` — трехлучевая вращательная схема в стиле GitHub с жидкими сопряжениями.
  - `mention` (`@`) — нестандартная спираль со скругленной геометрией в духе Maple Mono.
  - `magic-pen`, `magic-eraser`, `ai-magic-wand`, `ai-tokens` — фирменная 4-лучевая звездочка (`ai-spark`) отделена чистым воздушным зазором от основного корпуса инструмента/монет.
  - Для иконок, которые уже были эталонными в `v6` (`heart`, `heart-filled`, `add`, `close`, `reset`, `refresh`, `undo`, `edit`, `eraser`, `folder`, `open-folder`, `audio-file`, `restart`, `bluetooth`, `bluetooth-off`, `database`, `microphone`, `microphone-off`), сохранена их аутентичная пластика `Orig v6`.
