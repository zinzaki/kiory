# Kiory — финальная версия v6

Чистая поставка утверждённого каталога Kiory v6.

## Содержимое

- `Kiory Catalog v6 — итог.figcraft` — финальная редактируемая доска в формате FigCraft.
- `Kiory v6 — итог.png` — готовое изображение каталога (2400 × 2034).
- `icons/` — 301 финальная SVG-иконка. SVG имеют `viewBox="0 0 24 24"` и используют `currentColor` для цвета.
- `groups.json` — разбиение иконок по группам каталога.
- `families.json` — тематические категории иконок.

## Использование

Используйте файлы из `icons/` для внедрения в интерфейсы, а `.figcraft` — для редактирования каталога.
Цвет иконок задаётся через CSS `color` при встраивании SVG как разметки.
Обычный тег `<img>` не наследует `currentColor` от родительского элемента.

## Происхождение

Файлы взяты из `review/v6/final/`, `review/v6/` исходного проекта.
Содержимое иконок, итогового `.figcraft` и PNG оставлено без художественных изменений.
Из этой копии исключены старые версии, пробы, альтернативные эскизы, тестовые листы,
временные файлы, исходники старого генератора и его окружение.
Это чистая поставка результатов, а не восстановленная среда для запуска исторического генератора.
